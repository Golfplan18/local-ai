# de Bono AGO

## Trigger

Invoked when a mode needs to clarify purpose before choosing actions, formats, or outputs. The host mode supplies the task or deliverable; the lens supplies AGO: Aims, Goals, and Objectives.

## Core Structure

AGO separates three levels of purpose that are often blurred.

1. **Aim.** The broad direction or reason for acting.
2. **Goal.** The desired end state or target.
3. **Objective.** A concrete, checkable outcome or criterion.

The tool prevents format or execution choices from outrunning purpose. In Ora, it is especially useful when a project deliverable or structured output needs to be shaped around what the user is actually trying to accomplish.

## Application Steps

1. State the task or requested output.
2. Identify the broad aim: why is this worth doing?
3. Identify the goal: what state should be reached?
4. Identify objectives: what concrete qualities or deliverables would show success?
5. Check whether the proposed format serves the aim and goal.
6. Remove output requirements that do not serve the clarified objective.

## Detection Signals

- The requested format is clear but the purpose is fuzzy.
- A project has many activities but no shared success definition.
- A structured output needs to choose sections, fields, or depth.
- The user may be asking for a means rather than the real end.

## Critical Questions

- What is the broader aim behind this task?
- What goal would make the work successful?
- Which objectives are concrete enough to verify?
- Does the requested form serve the actual purpose?
- What can be removed because it does not support the aim, goal, or objective?

## Common Failure Modes

- **Objective inflation** - Detection: every desirable quality becomes mandatory. Correction: separate must-have objectives from nice-to-have traits.
- **Format-first drift** - Detection: the output template drives the work more than the purpose. Correction: restate AGO before choosing format.
- **Aim vagueness** - Detection: the aim is inspirational but not directive. Correction: translate it into a goal and objective.
- **Goal-objective collapse** - Detection: a broad goal is treated as a checkable objective. Correction: define observable completion criteria.
