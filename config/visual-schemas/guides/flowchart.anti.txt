The canonical wrong output degrades into a single-column linear list of rectangles with no lanes and decision diamonds that have only one outgoing edge (so a "PO match?" diamond silently drops the no-match path), plus an empty or whitespace `dsl`. It reads like a flat checklist, not a process: no roles, no exhaustive branching, bottleneck mentioned only in prose. The one rule that prevents it: every `{decision}` node MUST emit ≥2 labelled mutually-exclusive `-->|label|` edges, and the procedure MUST be partitioned into typed `subgraph` swimlanes with the constraint flagged on-canvas via classDef.
