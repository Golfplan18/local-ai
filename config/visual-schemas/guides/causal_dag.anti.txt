The canonical wrong output is a cramped "hairball": single-letter abstract node ids (`x [exposure]; y [outcome]; e; d; s`) that render as blank or white-on-white focal nodes with illegible labels, too many crossing arrows in a narrow column, and no visible separation between confounders and the causal path — judges scored these 4.3–5.5 ("blank, unlabeled core nodes," "white-on-white"). It can also degrade into a causal_loop_diagram by adding a feedback edge that creates a cycle (e.g. Churn -> Onboarding), which fails the acyclicity invariant. THE ONE RULE: every node gets a concrete human-readable id (never single letters), and the graph stays strictly acyclic with a clear exposure→mediator→outcome spine.
