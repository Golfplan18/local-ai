**Structural definition.** `type:"scatter"` is a QUANT-family Vega-Lite unit spec for a BIVARIATE relationship: two QUANTITATIVE fields on `x`/`y`, optional `color` to encode a third (categorical) dimension. Required spec keys: `$schema`, `data`, `mark` (point|circle|square|text), `encoding`, `caption{source,period,n,units}`. `mark` and `encoding` are required AT TOP LEVEL even if you also use `layer` — so a layered scatter must still carry a top-level unit `mark`+`encoding`. `transform` is NOT an allowed top-level key (additionalProperties:false), so a regression/loess trend can only live inside a `layer[]` item.

**Scatter vs. its confusable siblings.** Use scatter when BOTH axes are continuous measures of the SAME units of observation (accounts, stores, patients) and the point is the relationship/cluster/outlier. NOT `comparison` (one categorical axis, magnitude ranking). NOT `time_series` (x is time). NOT `quadrant_matrix` (named strategic quadrants, conceptual placement, not measured x/y). NOT `heatmap` (binned x×y density).

**The named failure modes (from judge ground truth — defeat these exactly):** (1) TOY POINT COUNT — winning lane had ~20+ points across 4 labeled groups; losing lanes rendered 3–5 monochrome points that "only weakly substantiate" the claim. Populate `data.values` with 20–30+ realistic rows and set `caption.n` to match the row count exactly. (2) BROKEN COLOR ENCODING — losers' region hue collapsed to a legend reading "undefined." ALWAYS give `encoding.color` a `field`, `type:"nominal"`, a `title`, AND an explicit `scale.domain` (the category list) + `scale.range` (one color each); never rely on implicit domain inference. (3) DATA CONTRADICTS CLAIM — one lane's points contradicted the message. Engineer the values so the cluster the prose names is visibly separated and genuinely demonstrates the claim.

**Layout/labeling rules.** Honest axes: `scale.zero:true` for dollar/count quantities (else populate `integrity_declarations.non_zero_baseline_justified`). Title every channel; format currency axes (`axis.format:"$,.0f"`). Keep legend off the data field (small `width`/`height` ~440×320). semantic_description: level_1 elemental MUST describe THIS scatter (axes, units, ranges, n, color dimension) — never bar-chart boilerplate; level_2 gives the correlation/slope sign + extrema; level_3 the perceptual cluster story; short_alt ≤150 chars naming the actual variables and the takeaway cluster.
