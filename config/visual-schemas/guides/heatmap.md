**Structural definition.** A heatmap is a QUANT-family Vega-Lite spec (Path A) rendering a 2D matrix: one categorical/ordinal field on `encoding.x`, another on `encoding.y`, and a *quantitative* field on `encoding.color`. `mark` MUST be `"rect"` or `"square"` (schema enum). The color field carries the data — x and y are just the grid. This is the rendering target for ACH matrices too.

**THIS type vs siblings it degrades into.** The #1 failure (judge notes) is the heatmap *collapsing into a different chart*: a single column or single row left after the model drops most of the matrix → it reads as a bar/dot strip, gutting the narrative. If you have one categorical axis and a quantity, that's a `comparison` (bar) chart, NOT a heatmap. A heatmap REQUIRES both axes populated for every combination — emit the full cross-product of rows×columns as `data.values`. With R rows and C columns you need exactly R×C objects.

**Specific failure modes from the judge notes.** (1) *Degenerate axis*: render collapsed to "2 rows × a SINGLE week column" (fidelity 3.5) — the entire temporal/second axis vanished. DEFEAT: enumerate every (row,col) cell explicitly; set `caption.n` = R×C and re-count your `values` array. (2) *Coarsened resolution*: 12 weeks silently binned to ~4 (0/4/8/12), fidelity 6.8 vs 9.0 — emit each discrete step, do not aggregate. (3) Winners (fidelity 9.0) had: single-hue sequential ramp, labeled axes, a *titled colorbar*, and rows ordered by the value (best→worst).

**Layout + labeling rules.** Use `scale.scheme` = sequential (`blues`, `viridis`, `greens`) for ordered data — NEVER rainbow/jet/turbo/spectral (Major block per §7.5/§7.6); diverging (`redblue`, `purpleorange`) only for data with a meaningful midpoint. Set `scale.domain` to state the value range explicitly (e.g. `[0,100]`). Give `encoding.x.title`, `encoding.y.title`, AND `color.title` (the color title IS the colorbar label — required). Sort `y` by the metric so the gradient reads cleanly. Provide `spec.caption` object with all four required fields: `source`, `period`, `n`, `units` (T15 hard-block if absent). `level_3_perceptual` must describe the 2D gradient direction (darkens down / lightens right), not restate numbers.
