The canonical wrong output is a causal_dag wearing a concept_map label: 6-10 nodes wired with bare arrows whose phrases are all "causes"/"leads to"/"affects" (or with `linking_phrases` left empty), plus one orphan node the model declared but never connected, and zero `is_cross_link` edges — so it renders as an unlabeled hairball that reads as a flowchart, not a network of checkable sentences. The one rule that prevents it: every proposition must read aloud as a true sentence "FROM <phrase> TO", each relation gets its OWN linking phrase, every declared concept id appears in at least one proposition, and 2-4 level-spanning edges are flagged `is_cross_link:true`.
