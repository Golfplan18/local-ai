The canonical wrong output is a heatmap that collapses to a degenerate strip — e.g. 4 channels × a SINGLE week column, or a 2-row grid — because the model emitted only a fraction of the row×column cross-product. The matrix loses its second axis and reads as a bar/dot chart, destroying the gradient story. A close runner-up: silently coarsening 12 discrete weeks into ~4 bins. THE ONE RULE THAT PREVENTS IT: emit one `data.values` object for EVERY (row,column) pair — exactly R×C of them — and set `caption.n` to R×C, then re-count the array to confirm. Secondary trap: a rainbow/jet/turbo `scale.scheme` on ordered data (Major block) — always use a sequential scheme (blues/viridis) with an explicit `scale.domain`.
