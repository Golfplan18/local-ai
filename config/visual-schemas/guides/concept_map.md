**Structural definition.** A concept_map (RELATIONAL family, Novak CXL) is a network of *propositions*: every edge is `concept --linking-phrase--> concept` and must read as a checkable sentence. Schema requires `focus_question`, `concepts[]` (each `id`,`label`,`hierarchy_level` integer ≥0), `linking_phrases[]` (`id`,`text`), `propositions[]` (`from_concept`,`via_phrase`,`to_concept`, optional `is_cross_link`). The integrity checker resolves every `from_concept`/`to_concept`/`via_phrase` against declared IDs — a typo'd or missing ID hard-fails. Soft warning fires if no proposition has `is_cross_link:true` (cross-links are the Novak-specific insight; always include 2-4).

**THIS type vs siblings it degrades into.** NOT a causal_dag (edges there are causal arrows with no linguistic phrase; concept_map edges are arbitrary verbs/relations: "is reduced by", "signals readiness for"). NOT a flowchart (no decision nodes/process order). NOT a mind map (mind maps have no propositional semantics — protocol §76 explicitly excludes them). If your edges all mean "causes", you've built a DAG, not a concept map.

**The specific failure modes from the judge (defeat all four).** (1) Orphan node — qwen scored 4.5 because "Disorganized" had zero edges; RULE: every concept id must appear in ≥1 proposition. Sweep before emitting. (2) Reversed/misrouted arrowhead — direction must match the phrase ("X is reduced by Y" means Y→X… read it aloud); a base driver hanging off the wrong parent tanks fidelity. (3) Uniformly repeated edge labels — the optimum lane lost points for the same phrase on many edges; give each proposition a DISTINCT linking phrase wherever the relation differs. (4) Hairball/cramped crossings — the premium (8.3) winner won by separating a clean vertical hierarchy (solid `hierarchy_level` ladder) from dashed `is_cross_link` edges, and connecting leaf concepts to multiple parents WITHOUT tangling.

**Layout + labeling rules.** Assign `hierarchy_level` as a genuine top-down ladder (0=root/focus answer at top, increasing downward); the compiler ranks by it, so a coherent ladder prevents crossings. Keep 6-10 concepts, 8-14 propositions — rich but legible. Mark genuinely level-spanning or lateral edges `is_cross_link:true` (rendered dashed) so they read as the non-obvious tensions, not noise. Linking phrases are short verb phrases (≤4 words), lower-case. `semantic_description` needs all three levels + `short_alt` ≤150 chars describing THIS map (mention concepts/pathways), never bar-chart boilerplate.
