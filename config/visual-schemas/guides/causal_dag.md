**Structural definition.** A causal DAG (Pearl/Hernán) is a *directed acyclic* graph encoding causal beliefs for identification: which variable causes which, so an analyst can read off confounders, mediators, and adjustment sets. CAUSAL family, Path A (DAGitty DSL → Graphviz). `spec` has exactly three keys (`additionalProperties:false`): `dsl`, `focal_exposure`, `focal_outcome`. The `dsl` is a DAGitty string: `dag { Node [type]; ...; A -> B; ... }`. Node types in brackets: `[exposure]`, `[outcome]`, `[latent]` (latent = unmeasured, rendered dashed); untyped nodes are observed covariates. INVARIANTS the integrity checker enforces: parser accepts dsl; graph ACYCLIC; `focal_exposure` and `focal_outcome` literally appear as node ids in the dsl.

**THIS type vs the sibling it's confused with.** Causal DAG ≠ causal_loop_diagram (CLD). CLD edges carry +/- POLARITY and the graph is deliberately CYCLIC (feedback loops). A DAG has NO polarity and MUST be acyclic — if you find yourself wanting a reinforcing loop, you picked the wrong type. DAG ≠ flowchart: nodes are variables, not process steps; arrows mean "causes," not "then."

**The specific failure modes from judge notes (defeat these).** (1) WHITE-ON-WHITE / BLANK FOCAL NODES — the single most-cited failure: exposure and outcome nodes rendered with invisible labels ("blank, unlabeled core nodes", "render white-on-white"). Defense: give every node a *concrete, human-readable* id (e.g. `Onboarding`, `Churn`, not `x`, `e`, `d`). Never use single-letter ids — they amplify the blank-label failure and read as garble. (2) ILLEGIBLE HAIRBALL — "cramped, overcrowded, illegible hairball of arrows." Defense: keep to 5–8 nodes; arrange a clear left→right causal spine exposure→(mediator)→outcome; let confounders fan in from common-cause sources. Don't over-edge. (3) The winning render explicitly *separated confounders from the causal path* and color-coded exposure/outcome — encode that structure: distinct confounder sources pointing into BOTH ends, mediator ON the spine, latent dashed.

**Layout + labeling rules.** focal_exposure first node, focal_outcome a sink. Mediator: exposure→M→outcome. Confounder: C→exposure AND C→outcome. Mark unmeasured confounders `[latent]`. Make `semantic_description.level_4_contextual` state the adjustment set (adjust for measured confounders, NOT the mediator). short_alt ≤150 chars, names THIS graph's variables.
