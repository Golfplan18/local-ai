The canonical wrong output degrades into a flowchart of verbs (boxes labeled "Validate payment", "Send email") with crossed arrows, a cosmetic `Active --> Active : maintain` self-loop, and no `[*]` terminal — exactly the low-scoring render the judge flagged ("crossed/mis-directed edges, dangling self-loop, no final state"). The other frequent garble is putting `"direction":"LR"` as a sibling key of `dsl` inside `spec`, which hard-fails `additionalProperties:false`. The one rule that prevents both: states are NOUNS the entity rests in, every machine declares `[*] --> first` and `last --> [*]`, and layout direction lives as a `direction LR` line INSIDE the dsl string — never as a spec field.
