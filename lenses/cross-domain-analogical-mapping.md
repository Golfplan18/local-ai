# Cross-Domain Analogical Mapping

## Trigger

Invoked when a mode needs to connect ideas across distant domains without being fooled by surface similarity. The host mode supplies the source and target domains; the lens supplies structure-mapping discipline: map relations and mechanisms before importing conclusions.

## Core Structure

Good analogies preserve relational structure. Weak analogies merely match surface features.

1. **Source domain.** The familiar or external domain used as the analogy.
2. **Target domain.** The domain being understood or explored.
3. **Objects.** Entities in each domain.
4. **Relations.** How the entities interact.
5. **Systematic structure.** Higher-order relations that make the analogy explanatory.
6. **Mapping limits.** Where the analogy stops working.
7. **Candidate transfer.** The hypothesis or design idea imported from source to target.

## Application Steps

1. Name the source and target domains.
2. List surface similarities and set them aside.
3. Map the relevant objects and relations in each domain.
4. Identify structural correspondences that preserve mechanism.
5. State what can be transferred and what cannot.
6. Generate at least one disanalogy that would break the mapping.
7. Return the analogy as a hypothesis generator, not proof.

## Detection Signals

- A synthesis requires transfer between distant bodies of knowledge.
- A user proposes "X is like Y" and needs to know if the analogy is real.
- A novel problem needs candidate mechanisms from another field.
- Surface resemblance is tempting but may mislead.

## Critical Questions

- Are the mapped similarities relational or merely superficial?
- What higher-order relation is preserved?
- Which part of the source domain should not transfer?
- What disanalogy would falsify the mapping?
- Does the analogy generate a testable hypothesis or only a metaphor?

## Common Failure Modes

- **Surface-match error** - Detection: the analogy rests on shared appearance or vocabulary. Correction: map relations and mechanisms.
- **Over-transfer** - Detection: every feature of the source is imported. Correction: state mapping limits.
- **Proof substitution** - Detection: the analogy is used as evidence. Correction: treat it as a generator of hypotheses to test.
- **Domain blindness** - Detection: target-domain constraints are ignored. Correction: identify what the target domain cannot inherit.
