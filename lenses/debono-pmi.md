# de Bono PMI

## Trigger

Invoked when a mode needs a fast balanced scan of an idea, proposal, option, or artifact. The host mode supplies the object under review; the lens supplies PMI: Plus, Minus, Interesting.

## Core Structure

PMI separates evaluation into three passes so the first reaction does not dominate.

1. **Plus.** What is good, useful, valuable, promising, or advantageous?
2. **Minus.** What is bad, risky, costly, weak, or harmful?
3. **Interesting.** What is notable, uncertain, generative, surprising, or worth exploring even if not clearly good or bad?

The "interesting" pass is not a miscellaneous bin. It captures novelty, second-order potential, ambiguity, and questions that binary evaluation would miss.

## Application Steps

1. State the object being evaluated.
2. Run the Plus pass without immediate qualification.
3. Run the Minus pass without cancelling the Plus pass.
4. Run the Interesting pass for uncertainties, pivots, and implications.
5. Synthesize the three passes into a balanced judgment or next question.

## Detection Signals

- The analysis risks becoming one-sided.
- A proposal needs quick but disciplined evaluation.
- Benefits and harms are both visible.
- The most valuable output may be a question rather than a verdict.

## Critical Questions

- What is genuinely positive here?
- What is genuinely negative here?
- What is interesting but not yet evaluative?
- Did any pass dominate before the others were complete?
- What does the Interesting column suggest we should investigate?

## Common Failure Modes

- **Two-column collapse** - Detection: Interesting becomes leftover plus/minus. Correction: reserve it for ambiguity and generative implications.
- **Politeness balance** - Detection: Plus items are invented to soften critique. Correction: name only real pluses.
- **Verdict rush** - Detection: synthesis happens before all passes. Correction: complete PMI first.
- **Symmetry illusion** - Detection: equal list length is treated as equal weight. Correction: weigh importance after listing.
