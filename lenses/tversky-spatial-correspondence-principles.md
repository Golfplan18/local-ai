# Tversky Spatial Correspondence Principles

## Trigger

Invoked when spatial-reasoning analysis needs to judge whether an external representation fits the structure of the thing represented. The host mode supplies the diagram, layout, map, or spatial claim; the lens supplies correspondence principles from spatial cognition.

## Core Structure

Spatial representations work when their visual-spatial structure corresponds to the conceptual, physical, temporal, or causal structure users need to reason about.

1. **Congruence.** Visual relations should match meaningful relations in the target.
2. **Proximity.** Related items should be near each other when closeness matters.
3. **Alignment.** Comparable elements should line up to support comparison.
4. **Directionality.** Left/right, up/down, and flow direction should fit cultural and task expectations.
5. **Perspective.** The representation should choose a viewpoint suited to the task.
6. **Cognitive load.** Spatial layout should reduce search and memory burden.
7. **Distortion tradeoff.** Useful maps may distort geometry to preserve task-relevant relations.

## Application Steps

1. Identify the reasoning task the representation must support.
2. Identify the target relations: physical, causal, temporal, hierarchical, or conceptual.
3. Check whether spatial relations in the representation correspond to target relations.
4. Find mismatches that create false inference or extra cognitive load.
5. Recommend layout changes that improve correspondence.

## Detection Signals

- A diagram, map, or interface feels confusing despite containing the right information.
- Spatial position implies a relation that may not be true.
- Users must mentally transform the representation to use it.
- The task requires comparison, sequence, hierarchy, route, or causal flow.

## Critical Questions

- What relation is space representing here?
- Does proximity mean conceptual relatedness, physical closeness, sequence, or nothing?
- Is the chosen orientation natural for the task?
- What inference will users make from layout alone?
- What distortion improves reasoning, and what distortion misleads?

## Common Failure Modes

- **Decorative layout** - Detection: space is used aesthetically but implies false relations. Correction: align layout with task relations.
- **Correspondence ambiguity** - Detection: users cannot tell what position means. Correction: define the mapping.
- **Mental-rotation burden** - Detection: users must constantly translate viewpoints. Correction: choose task-appropriate perspective.
- **Over-literal mapping** - Detection: geometric accuracy hurts reasoning. Correction: preserve task-relevant structure.
